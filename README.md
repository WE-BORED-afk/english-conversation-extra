# English Conversation + Extra

Static study web app covering **150 English conversation items** (pages 1–38 across TGAT 67–69 and A-Level 67–69) with Thai choice translations, green circular answer indicators, and **91 Extra synonym entries** (pages 1–89) linked to matching choices.

- **Main page:** `index.html` (zero build step, zero runtime JS dependencies)
- **Deploy:** Static publish root (`.`) configured in `netlify.toml`
